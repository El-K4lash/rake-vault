# Icône coupe (Wins)

![Aperçu|320](../../_img/Liic_icone_coupe_wins.webp)

Coupe dorée cartoon avec gros contour bleu nuit, dans le style des icônes du kit K4 (billets, couronne, horloge…). Sert d'icône pour les **victoires / wins / trophées** à côté d'une barre de compteur.

- **Catégorie** : [Interfaces](../Interfaces.md)
- **Sous-catégorie** : [Icônes & images](Ic%C3%B4nes%20%26%20images.md)
- **Type** : Icône (fond transparent)
- **Utilisée dans** : NEEDLE RUSH, `StarterGui.NeedleUI.HUD.Stats.WinsIcon`

## Utiliser dans Roblox

| Version | ID à mettre dans `ImageLabel.Image` | Fichier |
| --- | --- | --- |
| Coupe Creator Store (en jeu) | `rbxassetid://106849947182608` | `lib/icons/trophy_wins_store.png` |
| Coupe HD faite avec Figma | pas encore uploadée sur Roblox | `lib/icons/trophy_wins_figma.png` (512 px) |

Attention : `124852736220315` est l'ID du **Decal**. Pour un `ImageLabel`, il faut l'ID de l'**image** : `106849947182608`.

Pour uploader la version Figma : Studio → sélectionne l'`ImageLabel` → propriété **Image** → **Add Image…** → choisis `trophy_wins_figma.png`. Studio remplit l'ID tout seul.
